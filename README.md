# สถิติผู้ป่วยโรงพยาบาล

เว็บแอปแบบฝึกหัด Streamlit Data Visualization ใช้ Python, Pandas และ Streamlit
อ่านข้อมูล 201 แถวจาก `data.csv` ซึ่งระบุแหล่งข้อมูลเป็นสำนักงานสถิติแห่งชาติ
ข้อมูลมีปี พ.ศ. 2560 และ 2565

## เปิดแอปบนเครื่องนี้

ดับเบิลคลิก `run.bat` ในโฟลเดอร์งาน แล้วเปิด http://localhost:8501
หรือเปิด PowerShell ในโฟลเดอร์งานแล้วรัน:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

ปล่อยหน้าต่างที่รันแอปไว้ระหว่างใช้งาน กด Ctrl+C เพื่อหยุดแอป

## ติดตั้งบนเครื่องใหม่

ติดตั้ง Python 3.12 แล้วเปิด PowerShell ในโฟลเดอร์ที่มี `app.py`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

ต้องใช้อินเทอร์เน็ตตอนติดตั้งแพ็กเกจ หลังติดตั้งแล้วแอปอ่าน CSV จากเครื่องได้

## การใช้งานและการคำนวณ

- เลือกภูมิภาคและประเภทผู้ป่วยจากแถบด้านข้าง ทั้งสองกราฟจะเปลี่ยนตามตัวกรอง
- กราฟเส้นแสดงผลรวมจำนวนผู้ป่วยแต่ละปี โดยรวมขนาดโรงพยาบาลในภูมิภาคที่เลือก
- เลือกปีเพื่อเปลี่ยนกราฟแท่งเปรียบเทียบจำนวนผู้ป่วยแต่ละขนาดโรงพยาบาล
- ยอดสรุปด้านบนเป็นจำนวนผู้ป่วยของภูมิภาค ประเภทผู้ป่วย และปีที่เลือก
- เปิดตารางใต้กราฟเพื่อดูข้อมูลของภูมิภาคและประเภทผู้ป่วยที่เลือกทุกปี
- เลือกภูมิภาคและประเภทผู้ป่วยครั้งละหนึ่งรายการ เพื่อไม่รวมยอดประเทศซ้ำกับรายภูมิภาค หรือรวมประเภท “รวม” ซ้ำกับประเภทผู้ป่วยย่อย
- กราฟใช้เฉพาะปีที่มีใน CSV และไม่มีการประมาณค่าปีระหว่างกลาง

## ไฟล์งาน

- `app.py`: โค้ดแอป
- `data.csv`: ชุดข้อมูล
- `requirements.txt`: แพ็กเกจที่ใช้
- `run.bat`: ตัวเปิดแอปสำหรับ Windows
- `.venv`: สภาพแวดล้อม Python บนเครื่องนี้ ไม่ต้องนำไปส่งหรืออัปโหลด

## ผลการตรวจสอบ

ทดสอบเมื่อ 12 ตุลาคม 2569 ด้วย Python 3.12, Streamlit 1.65.0 และ Pandas 3.0.6

- ใช้ Streamlit AppTest ทดสอบภูมิภาค 6 รายการ × ประเภทผู้ป่วย 3 รายการ × ปี 2 รายการ รวม 36 ชุด
- ทุกชุดแสดงกราฟ 2 กราฟและตารางข้อมูล พร้อมยอดสรุปตรงกับผลรวมจาก CSV
- กรณีไฟล์หาย คอลัมน์ไม่ครบ และไฟล์มีเฉพาะหัวตาราง แสดงข้อความแจ้งโดยไม่มี exception ในหน้าแอป
- เปิดเซิร์ฟเวอร์จริงบน localhost และตรวจ health endpoint ได้ผล `ok`
